# PvP / APVP Gating

The minimap PK toggle sends `uif("apvp", <bool>, false)`, persisted as before by `auth.UpdateInterfaceSetting` into `PMProcessData["interfaceData"]["apvp"]` plus `player.character_interface_settings`. `PVPStartClient(targetCid[, force])` is now its own handler (`pk/pvp_start.go`) that gates on the **target's** `apvp` flag (the attacker can only freely engage targets who have opted into PvP): when the target's `apvp` is off the server hard-blocks the attack regardless of any client `force` arg (sends `onMidNote` "Mục tiêu chưa bật PK, không thể tấn công." to the attacker and returns `{success:false, blocked:"target_apvp_off"}`); the Flash retry-with-`force=true` path is intentionally not honored because the user asked for a strict opt-in PvP gate. When the target's `apvp` is true the server creates a `combat.Battle{Type:PVP}` via `combatService.StartPVPBattle` (attacker char/pet at canonical positions 10/15, target char/pet at 0/5) and dispatches per-viewer entry to both connections: `SetBattleID`, `AddWatcher`, owner-pet `onUpdatePet` HP/MP sync, owner-char `onSetCharState{state:5}`, scene-broadcast `onSetCharState{state:5}` to other players in the same map, and finally two `onBattleStart` payloads sharing one canonical `cList` — `guest:false` to the attacker, `guest:true` to the target. The Flash client's `BattleStage.setGuestGroupPos` (`BattleStage.as:803-825`) handles the visual mirror so each player sees themselves on the bottom of the screen. PvP turn resolution waits for **both** characters' commands before processing, with a **25s** per-turn deadline (vs 30s default for PvE). Two domain-level changes back this: `Battle.MissingPlayerCommandActors` includes `SideEnemy` characters when `BattleType == BattleTypePVP`, and `combat/group_battle.battlePlayerCharacters` returns both sides for PvP — flowing into `setBattleRoundDeadlines`/`sendCmdReadyToParticipants`/`sendBattleEndCallbacks`. `appbattle.Service.SetTurnDeadlineWithDuration` is the new explicit-duration setter; `setBattleRoundDeadlines` picks 25s for PvP and the default 30s for PvE. Initial deadlines for both PvP characters are set in `pk/pvp_start.go` immediately after each `onBattleStart`. Skill-actions/damage resolution beyond the gating remains the existing turn processor. Default `apvp` in `defaultInterfaceData()` is `false`.
