# Stat Feature Foundation

Stat-affecting progression systems beyond equipment now use a shared foundation:

- `data.data_tbl_stat_feature` catalogs the researched systems, ownership, and readiness
- `player.character_stat_features` stores per-character JSONB feature state
- `player.pet_stat_features` stores per-pet JSONB feature state
- `player.character_progression.awaken_*` and `player.character_progression.soul_*` columns remain the authoritative numeric progression source for Awakening and Soul (moved out of `player.characters` in the 2026-04-18 split — see `database-infrastructure.md`)

Integration points:

- character-side bonuses plug into `item.Service.AggregateEquipmentStats()` through a character bonus provider
- pet-side bonuses plug into `pet.Service.enrichPet()` through a feature bonus provider
- login root state plugs into `auth` through a login state provider used by `onChooseCharactor`
